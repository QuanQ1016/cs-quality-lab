# 客服工单趋势分析

> 运行模式：规则统计 + Mock LLM 综述

## 分析维度
- **时间趋势**：看量是否在抬升，避免被单日噪声带偏
- **类型分布**：决定排班和知识库补强方向
- **优先级与时长**：判断 SLA 是否失守
- **满意度**：把“忙完了”和“用户认可”分开
- **未关闭与复发**：找出系统性问题，而不是再回一条话术

## 关键发现
最近 11 天共 50 张工单，未关闭 8 张，平均满意度 2.36。 支付与退款是当前最需要盯的两条线：前者量在后半段抬升且重复扣款反复出现，后者处理时长长、差评多，还有垫付运费未报销。 建议今日先清未关闭的高优工单，并单独排期修支付重复扣款和退货运费报销链路。 系统标出的异常均来自规则检测，不是模型臆测。
